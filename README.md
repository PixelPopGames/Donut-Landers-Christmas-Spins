- `style.css`
- `game.js`
- `.nojekyll`

Do not upload only the ZIP file. Extract it first, open the `Donut-Landers-Christmas-Spins-Fixed` folder, then upload the files above from inside that folder directly into the repository root.

## Game
A mobile-friendly Christmas slot game with virtual coins, three reels, generated sound effects, adjustable bets, matching-symbol payouts, and the 🌈 → 👻 → 🍫 500× jackpot. Sound begins after the player interacts, due to browser autoplay restrictions. Coin totals reset when the page is reloaded. This version uses emoji symbols rather than custom Donut Landers image assets; no external image or audio files are required.
