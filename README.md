# Donut Landers: Christmas Spins

## Upload to GitHub Pages

**Important:** Upload the *contents* of this folder directly into the root of your repository `PixelPopGames/Donut-Landers-Christmas-Spins`. Do not upload the ZIP itself and do not put the files inside another folder.

The repository root must show:

- `index.html`
- `style.css`
- `game.js`
- `.nojekyll`
- `assets/` (folder containing `sprinkles.png`, `ghost.png`, `chocolate-von-donut.png`, and `donut-landers-trio.png`)

In GitHub, open the repository → **Add file → Upload files**. Drag in those four files and the `assets` folder, then commit to `main`. Wait for the Pages deployment to finish in the **Actions** tab. Visit https://pixelpopgames.github.io/Donut-Landers-Christmas-Spins/ and hard-refresh if you previously loaded the broken version.

## Game features

- Mobile-friendly three-reel Christmas slot game.
- Uses the Donut Landers character artwork recovered from the earlier project.
- The jackpot is Sprinkles → Ghost → Chocolate Von Donut, in that exact left-to-right order (500× bet).
- Holiday symbol wins, adjustable virtual bets, sound effects generated in the browser, help panel, new-game reset, and saved virtual coin/best-win values when browser storage is available.
- No build tools, frameworks, server, or external JavaScript libraries are required. Google Fonts is optional; fallback fonts are built in.

Virtual coins only; no real-money gambling.
